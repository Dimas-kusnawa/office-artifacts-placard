Competition slug: `u-coral-ibis-18-office-artifacts-the-one-line-placard-3af971d2`

`main.py` (Python 3.13, standard library only, deterministic) writes one
line — a museum placard for an ordinary office object treated as an ancient
artifact — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

The placard (176 characters, one line):

> Lanyard, c. 2019. Woven nylon, plastic clip. Worn at the throat to prove its bearer belonged to the tribe; the badge it carried was never once read. Donated by Human Resources.

Run it with:

```sh
python3 main.py
```
